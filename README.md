# 🚀 المهندس لقمان محمد الهتاري | Loqman Al-Hetari
### بورتفوليو رقمي تفاعلي عالي الأداء • Professional Interactive Portfolio

بورتفوليو مهني تفاعلي حديث يجمع بين **تحليل البيانات (Data Analytics & BI)**، **هندسة نظم الويب المتكاملة (Full-Stack Web Engineering)**، و**توظيف الذكاء الاصطناعي لرفع كفاءة الأعمال**.

---

## 🌟 أبرز مميزات البورتفوليو (Key Features)

- ⚡ **واجهة أولى حية (Living Hero Section):**
  - شارة خضراء نابضة لحالة التفرغ الفوري للعمل (`● متاح للعمل المباشر وعن بُعد`).
  - ساعة رقمية حية بتوقيت صنعاء (`GMT+3`) تعمل لحظياً بالثواني.
  - عنوان حركي متجدد (Dynamic Role Rotator) يبرز التخصصات الثلاثة بدقة.
  - مجسم بيانات تفاعلي 3D (Three.js WebGL) يتجاوب مع حركة الفأرة ولمس الهاتف بثبات 60 FPS.
- 🔮 **مصفوفة المهارات الذكية (Spotlight Hover & Telemetry):**
  - تأثير التوهج الضوئي الشعاعي (Spotlight Radial Glow) المتبع لمؤشر الفأرة واللمس.
  - مؤشرات أداء تفاعلية متحركة (Proficiency Telemetry Gauge) لعمق إتقان الأدوات.
- 💻 **استعراض المشاريع بنوافذ حية (Interactive macOS Windows & Bento Grid):**
  - نافذة مشروع **DATX** التفاعلية بـ 3 تبويبات حية:
    1. *معمارية Single Source of Truth وقاعدة بيانات MySQL.*
    2. *نظام إدارة الندوات اللحظية وحماية روابط Zoom للطلاب.*
    3. *استقرار الخادم السحابي (Ubuntu 22.04 LTS & Nginx Reverse Proxy) وزمن استجابة <38ms.*
  - بطاقة تحليلات **Power BI & SQL** بخط بياني تفاعلي (Interactive Sparkline).
  - محاكاة **Three.js WebGL** و **GSAP ScrollTrigger** داخل بطاقات المشاريع.
- 📱 **تجربة هاتف استثنائية (Ultra-Responsive Mobile Experience):**
  - قائمة تنقل سريعة (☰ / ✕) منسدلة بزجاج داكن فاخر مع روابط مباشرة.
  - زر محادثة فورية عبر واتساب وزر تحميل السيرة الذاتية (CV).
  - مساحات لمس مريحة (Touch Targets >= 48px) ودعم فيزيائي كامل للاهتزاز (`active:scale-95`).
- 🧭 **نظام التمرير الذكي (Scroll-Spy Navigation):**
  - تتبع تلقائي للقسم النشط مع التمرير ومزامنة القائمة العلوية.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **الواجهة:** React 19, TypeScript, Vite
- **التصميم:** Tailwind CSS, Arabic Cairo Typography, JetBrains Mono
- **الحركات:** Framer Motion, Lenis Smooth Scroll
- **الرسوم ثلاثية الأبعاد:** Three.js (WebGL Procedural Rendering)
- **الأيقونات:** Lucide Icons & Official Verified Tech SVGs
