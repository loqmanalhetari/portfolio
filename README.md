## 👤 نبذة عن الشخصية والهوية المهنية (About Loqman)

مرحباً بك! أنا **لقمان محمد الهتاري**، متخصص في **نظم المعلومات الإدارية (MIS)**، أجمع بين رؤية الأعمال الاستراتيجية والقدرة الهندسية البرمجية الصلبة. 

أنطلق في مسيرتي المهنية من ركائز ثلاث متكاملة تصنع الفارق في أي فريق عمل تقني أو مؤسسي:

1. **تحليل البيانات وذكاء الأعمال (Data Analytics & Business Intelligence):**  
   هندسة واستعلام قواعد البيانات العلائقية المعقدة بـ **SQL Server**، ونمذجة البيانات بأسلوب **Star Schema**، وتصميم لوحات مؤشرات الأداء الحيوية في **Power BI** باستخدام دوال **DAX** المتقدمة لتحويل الأرقام الصامتة إلى قرارات تنفيذية رابحة.
2. **هندسة نظم وتطبيقات الويب (Full-Stack & Systems Engineering):**  
   بناء واجهات رقمية عصرية فائقة السرعة والتجاوب باستخدام **React 19, TypeScript, Tailwind CSS, Material UI**، وتطوير معمارية النظم الخلفية الموحدة (Single Source of Truth) عبر **NestJS & MySQL**.
3. **التوظيف العملي والذكي للذكاء الاصطناعي (AI-Augmented Productivity):**  
   لستُ باحثاً نظرياً في خوارزميات الذكاء الاصطناعي، بل **مهندس ومحلل بارع في توظيف أدوات ونماذج الذكاء الاصطناعي التوليدي** لمضاعفة سرعة الإنجاز، وأتمتة معالجة البيانات، وتدقيق الجودة، واختصار دورة حياة المشاريع من أسابيع إلى أيام.

## 🎨 فلسفة هذا البورتفوليو وإنجازاته التقنية (The Portfolio Engineering)

لم أرد لهذا البورتفوليو أن يكون مجرد سيرة ذاتية مسطحة أو صفحة نصوص جامدة، بل قمت بهندسته وتصميمه ليكون **تطبيقاً تفاعلياً حياً (Interactive Digital Showcase)** يثبت عملياً قدراتي في هندسة الويب وتصميم تجارب المستخدم (UI/UX) العالمية:

### ⚡ 1. الواجهة الأولى الحية (The Living Hero Section):
- **شارة الحالة الحية (Live Pulse Indicator):** وسم أخضر نابض يعلن التفرغ التام للعمل الحضوري وعن بُعد (`● متاح للعمل المباشر وعن بُعد`).
- **ساعة رقمية حية بتوقيت صنعاء (`GMT+3`):** تعمل لحظياً بالثواني لتعكس الحيوية والتحديث المستمر.
- **عنوان حركي ديناميكي (Role Rotator):** يتبدل بسلاسة فيزيائية بين التخصصات الثلاثة لإيصال القيمة المهنية في ثوانٍ معدودة.
- **مجسم بيانات ثلاثي الأبعاد تفاعلي (Three.js WebGL):** مجسم شبكي كروي إجرائي يدور بخفة متناهية ويتفاعل مع حركة المؤشر ولمس الهاتف بدون أي هبوط في الفريمات (ثابت على **60 FPS**).

### 🔮 2. مصفوفة المهارات الذكية (Spotlight & Telemetry Matrix):
- **تأثير الإضاءة التفاعلية (Spotlight Radial Glow):** بطاقات تفاعلية تتبع حركة الفأرة وإصبع المستخدم بهالة ضوئية خافتة مستوحاة من كبرى منصات التقنية العالمية (Linear & Vercel).
- **شريط قياس الأداء اللحظي (Proficiency Telemetry):** مقياس بصري متحرك يوضح عمق الخبرة والتطبيق الفعلي لكل مهارة.

### 💻 3. استعراض المشاريع بنوافذ حية (Interactive macOS Bento Grid):
- **مشروع DATX:** نافذة متصفح تفاعلية حقيقية مع **3 تبويبات قابلة للنقر الحي**:
  1. *معمارية الـ SSOT وقاعدة بيانات MySQL الموحدة (15+ جدول علائقي).*
  2. *نظام إدارة الندوات اللحظية مع حماية روابط Zoom حصراً للطلاب المسجلين.*
  3. *استقرار الخادم السحابي Ubuntu 22.04 LTS و Nginx Reverse Proxy بزمن استجابة `< 38ms`.*
- **مشروع Power BI & SQL:** لوحة تحليلات داكنة مع خط بياني تفاعلي (Interactive Sparkline) ومؤشر أداء دقيق.
- **تجارب Volt 3D و Luqma:** محاكاة حركية تفاعلية لرسوم Three.js وتأثيرات GSAP ScrollTrigger السينمائية.

### 📱 4. تجربة هاتف فائقة السلاسة (Ultra-Responsive Mobile UX):
- **قائمة تنقل سريعة (☰ / ✕):** درج جانبي زجاجي فاخر مع وصول مباشر لكافة الأقسام وأزرار فورية لمحادثة واتساب وتحميل الـ CV.

## 🛠 التقنيات والأدوات الأساسية (Core Tech Stack)

- **الواجهات والتفاعل:** React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lenis Scroll.
- **الرسوم ثلاثية الأبعاد:** Three.js, WebGL.
- **تحليل البيانات وذكاء الأعمال:** SQL Server, Power BI, DAX, Power Query, Excel Pivot, Python.
- **الأنظمة الخلفية وقواعد البيانات:** NestJS, Prisma ORM, MySQL, REST APIs, JWT, RBAC.
- **الخوادم والبنية التحتية:** Linux (Ubuntu), Nginx Reverse Proxy, Git, GitHub Actions CI/CD.

## 🚀 التشغيل والتطوير المحلي (Local Setup)

```bash
# استنساخ المستودع
git clone https://github.com/loqmanalhetari/portfolio.git

# الدخول للمجلد
cd portfolio

# تثبيت الحزم البرمجية
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية عالية الأداء
npm run build
```
